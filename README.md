# Acespot

### A Full stack ecommerce platform only for electronic items

A full-stack electronics e-commerce platform built with **Next.js 15**, **Clerk**, **MongoDB**, **Inngest**, and **Tailwind CSS**. The platform enables users to browse electronics, manage carts, place orders, while providing sellers with a dedicated dashboard to manage products and orders.
